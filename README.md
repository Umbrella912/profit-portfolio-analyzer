# profit-portfolio-analyzer

**Live app:** https://main.d3fevib98outvi.amplifyapp.com/

A privacy-first, browser-only profitability analyzer: upload sales CSVs, map columns, and explore 60+ interactive charts, side-by-side comparisons and PDF reports. No data ever leaves your browser.

- Hosted on AWS Amplify (build spec: `amplify.yml`)
- Demo data: `sample-data/superstore.csv` (click **Load Superstore data**)
- Project presentation: [`presentation/Profit-Portfolio-Analyzer.pptx`](presentation/Profit-Portfolio-Analyzer.pptx)
